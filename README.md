# hackernews — Hacker News 每日报告

每天一期的 Hacker News 每日报告，HTML 归档。

## 内容

- 每期覆盖 HN 首页约 30 条（首页快照），每条含中文摘要、简析、关键事实、社区观点、原文链接与 HN 讨论链接。
- 按日期命名：`YYYY-MM-DD.html`。
- `index.html`：归档首页，链接到最新一期。

## 往期

## 数据说明

- 每期基于 HN 首页快照，不是全天全部投稿。
- 排名、标题、链接、分数、评论数按快照原始顺序展示，不按分数重排。
- 2026-10-15 原版因数据不实，已按真实快照重建为更正版。

## 更新

- 每日 08:12（America/Los_Angeles）左右生成新一期并推送。
